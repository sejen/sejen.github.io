Rime

介绍 Rime 输入法在 Windows、macOS、Linux 和 iOS 上的安装与使用。

Rime 是一个开源、跨平台的输入法引擎。它本身不是某一个单独的输入法应用，而是一套输入法框架；在不同系统上，会通过不同前端接入系统输入法。

常见平台对应关系：

  • Windows：小狼毫 Weasel。
  • macOS：鼠须管 Squirrel。
  • Linux：IBus Rime、Fcitx Rime 或 Fcitx5 Rime。
  • iOS：仓输入法 Hamster。

Rime 的优势是可定制、无广告、输入方案丰富。拼音、双拼、五笔、仓颉、注音、粤拼等方案都可以通过配置文件管理，也可以同步自己的词库和习惯。

Windows：小狼毫 Weasel#

Windows 上通常使用“小狼毫”，也就是 Weasel。

项目地址：https://github.com/rime/weasel

安装方式：

  1. 打开 Weasel GitHub Releases。
  2. 下载最新的安装包。
  3. 按安装向导完成安装。
  4. 在 Windows 输入法设置里启用“小狼毫”。

安装后可以通过开始菜单里的“小狼毫算法服务”或“小狼毫输入法设定”进入配置。修改配置后，通常需要执行“重新部署”才能生效。

适合 Windows 用户关注的配置：

  • 候选词横排或竖排。
  • 简体、繁体切换。
  • 输入方案选择。
  • 用户词库和自定义短语。
  • 皮肤样式和候选窗口外观。

macOS：鼠须管 Squirrel#

macOS 上通常使用“鼠须管”，也就是 Squirrel。

项目地址：https://github.com/rime/squirrel

可以通过 Homebrew 安装：

brew install --cask squirrel

安装后在“系统设置”里的“键盘”输入法设置中添加“鼠须管”。如果修改了配置文件，需要点击菜单栏输入法图标，执行“重新部署”。

macOS 上常见配置位置：

~/Library/Rime

这个目录里会放输入方案、用户配置、词库和补丁文件。日常迁移 Rime 配置时，通常也是同步这个目录。

Linux：IBus / Fcitx#

Linux 上 Rime 通常通过输入法框架接入，常见选择是 IBus 或 Fcitx/Fcitx5。

项目地址：

  • IBus Rime：https://github.com/rime/ibus-rime
  • Fcitx Rime：https://github.com/fcitx/fcitx-rime
  • Fcitx5 Rime：https://github.com/fcitx/fcitx5-rime

如果使用 Ubuntu / Debian，可以安装 IBus Rime：

sudo apt install ibus-rime

如果使用 Fcitx5，可以安装 Fcitx5 Rime：

sudo apt install fcitx5-rime

Arch Linux 可以使用 pacman：

sudo pacman -S ibus-rime
sudo pacman -S fcitx5-rime

Linux 上安装完成后，还需要在系统输入法框架里启用 Rime。不同桌面环境的入口不完全一样，但大致流程都是：安装输入法框架、安装 Rime 插件、在输入法配置里添加 Rime、重新登录或重启输入法服务。

常见配置目录：

~/.config/ibus/rime
~/.local/share/fcitx5/rime

实际路径取决于你使用的是 IBus 还是 Fcitx5。

iOS：仓输入法 Hamster#

iOS 上可以使用“仓输入法”，也就是 Hamster。它是基于 Rime 的 iOS 输入法，支持导入 Rime 配置。

项目地址：https://github.com/imfuxiao/Hamster

App Store：https://apps.apple.com/cn/app/id6446617683

安装后需要在 iOS 里启用键盘：

  1. 打开“设置”。
  2. 进入“通用”。
  3. 进入“键盘”。
  4. 添加“仓输入法”。

iOS 输入法受系统限制更多，配置导入、文件访问和权限行为会和桌面系统不同。适合的方式是先在电脑上维护 Rime 配置，再把稳定配置导入到手机。

配置文件#

Rime 的配置主要是 YAML 文件。常见文件包括：

  • default.custom.yaml：全局配置补丁。
  • squirrel.custom.yaml：macOS 鼠须管配置补丁。
  • weasel.custom.yaml：Windows 小狼毫配置补丁。
  • *.schema.yaml：输入方案配置。
  • *.dict.yaml：词库文件。

Rime 的配置思路是“补丁优先”。尽量不要直接改系统自带方案文件，而是在 *.custom.yaml 里写自己的补丁。这样升级输入法或输入方案时，不容易覆盖自己的配置。

雾凇拼音#

雾凇拼音是一套开箱即用的 Rime 简体中文配置，包含全拼、常见双拼方案、长期维护的中英词库、Emoji、日期时间、农历、计算器、拆字反查、错音错字提示等功能。

项目地址：https://github.com/iDvel/rime-ice

它适合不想从零开始配置 Rime 的用户。安装 Rime 前端后，把雾凇拼音部署到用户配置目录，再重新部署，就可以直接使用一套完成度比较高的简体中文输入体验。

手动安装方式：

  1. 下载雾凇拼音仓库压缩包。
  2. 清空当前 Rime 用户配置目录。
  3. 将压缩包里的文件复制到 Rime 用户配置目录。
  4. 重新部署 Rime。

也可以使用 plum 安装：

bash rime-install iDvel/rime-ice

部署完成后，可以按 F4 切换输入方案或开关功能。雾凇拼音包含多个双拼方案，如果使用小鹤双拼、自然码、微软双拼等方案，可以在方案选单里切换。

plum#

plum，也叫“东风破”，是 Rime 的配置管理工具。它可以安装和更新 Rime 输入方案，也可以从 GitHub 仓库安装第三方配置。

项目地址：https://github.com/rime/plum

安装 plum：

cd ~
git clone https://github.com/rime/plum.git plum
cd plum

安装输入方案或配置：

bash rime-install iDvel/rime-ice

如果使用 Fcitx5，必要时可以指定前端：

rime_frontend=fcitx5-rime bash rime-install iDvel/rime-ice

如果 Rime 配置目录不在默认位置，也可以显式指定：

rime_dir="$HOME/.local/share/fcitx5/rime" bash rime-install iDvel/rime-ice

plum 的好处是更新更方便。以后进入 ~/plum 后重新执行安装命令，就可以拉取对应配置的新版本。对于雾凇拼音这类长期维护的配置，用 plum 管理会比手动复制文件更省心。

总结#

Rime 适合想要长期维护输入习惯的人。它不是最省心的输入法，但胜在稳定、开源、可迁移、可定制。

各平台可以这样选择：

  • Windows：小狼毫 Weasel。
  • macOS：鼠须管 Squirrel。
  • Linux：IBus Rime 或 Fcitx5 Rime。
  • iOS：仓输入法 Hamster。

如果只是想快速开始，可以先安装对应平台前端，再使用雾凇拼音这类开箱即用配置。等输入稳定后，再逐步迁移自己的词库、短语和外观配置。
